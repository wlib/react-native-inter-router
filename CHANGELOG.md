# Changelog

All notable changes to this project will be documented here. The project uses
[Semantic Versioning](https://semver.org/).

## 0.1.0 - Unreleased

### Added

- Canonical string and structured `Href` handling with bracket path patterns.
- Pure path, query, active-route, press-event, and external URL utilities.
- Adapter contract with frozen capabilities and configurable unsupported
  operation handling.
- Provider-driven and statically bound React hooks, Link, and Redirect.
- Next.js App Router, Expo Router, TanStack Router/Start, React Router, and
  deterministic memory adapters.
- Shared web/native ESM graphs, Node16/NodeNext-compatible declarations,
  legacy Metro shims, and strict package tarball verification.
